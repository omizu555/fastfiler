## A. 高レバレッジ (タブ+分割+速度を直接強化)

### A1. コマンドパレット (`Ctrl+P`)
- **内容**: タイプして「開いている全タブ/ペインのフォルダ」「ブックマーク」
  「全アクション/ユーザーコマンド」へ曖昧一致でジャンプ。VSCode 風。
- **なぜ**: 26 ペインを行き来する使い方では、目的の文脈へ最短で飛べるのが速度に直結。
  タブ思想 (文脈切替) の完成形。
- レバレッジ: ★★★ / 規模: 中 / 既存資産: `TextInput`、検索の曖昧一致ロジック、
  タブ/ペイン列挙 (app.rs)。新規はオーバーレイ UI とスコアリング。

### A2. ライブフィルタ (`/` キー)
- **内容**: 現在フォルダの一覧を、打ちながら部分一致で絞り込む
  (Ctrl+F の再帰検索とは別。表示中リストの即時間引き)。
- **なぜ**: 大量ファイルフォルダで目的のファイルへ瞬時に到達。速度価値そのもの。
  IDEAS #3「インクリメンタルサーチ (再実装待ち)」の上位互換。
- レバレッジ: ★★★ / 規模: 小〜中 / 既存資産: `entries` のフィルタ表示、
  検索バー UI パターン (pane.rs)。`uniform_list` はフィルタ後 Vec を渡すだけ。

### A3. ワークスペースプリセット (名前付きレイアウト)
- **内容**: 「タブ+分割構成のセット」を名前を付けて保存/復元
  (例: 経理用 / 開発用)。現状のセッション永続化の手動・複数版。
- **なぜ**: 用途ごとに作業環境を丸ごと切替。IDEAS #10「パネルプリセット」の具体化。
- レバレッジ: ★★★ / 規模: 中 / 既存資産: `session.rs` の `SessionData`
  シリアライズをそのまま名前付き複数スロットに拡張。

### A4. 選択フォルダ → 一括でタブ/分割に展開
- **内容**: 複数フォルダを選択 → それぞれ新ペイン (分割) or 新タブで開く。
- **なぜ**: マルチペイン作業の起点を 1 操作で構築。コア価値の入口を加速。
- レバレッジ: ★★☆ / 規模: 小 / 既存資産: タブ/ペイン生成 (app.rs)、`selected_paths`。

### A5. 一括リネーム (連番 / 正規表現)
- **内容**: 複数選択にパターン適用してまとめてリネーム
  (`{n}` 連番 / 検索置換 / 大文字小文字)。プレビュー付き。
- **なぜ**: ファイラ定番の power-user 機能。整理作業の生産性が跳ねる。
- レバレッジ: ★★☆ / 規模: 中 / 既存資産: `file_ops::rename_path_no_overwrite`、
  Undo 基盤 (`UndoOp::Rename` を複数積めば取り消しも効く)、モーダル UI。

## B. 小粒だが毎日効く

### B1. パスコピーのバリエーション
- フルパス / 名前のみ / `"` 囲み / `/` 区切り (POSIX 風) をワンキー or サブメニューで。
- スクリプトや別アプリへ貼る時に地味に最強。規模: 小 / 既存: `win_clipboard` のテキスト書き込み。

### B2. オンデマンドのフォルダサイズ計算 (du)
- フォルダ選択 → 再帰サイズを算出してステータス/列に表示。
- 既存資産: `file_jobs` に `scan_size` 相当が既にある。バックグラウンドジョブ化で UI を止めない。規模: 小〜中。

### B3. ペイン管理クイックアクション
- 分割の swap (左右入替) / 比率均等化 / 現ペイン一時最大化 (zen トグル)。
- 分割を多用するほど効く。規模: 小 / 既存: BSP ツリー操作 (app.rs)。

### B4. 変更ファイルのハイライト
- watcher で外部変更を検知した行を一瞬光らせる (どれが更新されたか目で追える)。
- 既存資産: watcher の `fs-change` は既に届いている。規模: 小 (行スタイルに時限装飾)。

### B5. ペイン端へのドラッグで新規分割
- フォルダをペインの端 (上下左右) にドロップ → その方向に分割して開く。
- 既存の内部 D&D + 分割生成の組合せ。規模: 中 (ドロップゾーンの端判定 UI)。

### B6. ASCII ツリーのエクスポート (IDEAS #24 の UI 配線)
- 選択フォルダのツリーをテキスト化してクリップボード/ファイルへ。
- 既存資産: `fastfiler-domain/src/ascii_tree.rs` が**実装済み・UI 未配線**。規模: 小。

## おすすめ着手順 (私見)

1. **A2 ライブフィルタ** — 規模小で速度価値が即体感できる
2. **A1 コマンドパレット** — 多ペイン運用の本命。A2 の UI 資産を流用できる
3. **A5 一括リネーム** or **A3 ワークスペースプリセット** — どちらも中規模で満足度高

B 群 (特に B1 パスコピー / B6 ASCII ツリー) は隙間に差し込める即効ネタ。

## メモ: 既に部分実装があり「配線するだけ」のもの

- ASCII ツリー (B6): `ascii_tree.rs` あり
- フォルダサイズ (B2): `file_jobs` の scan ロジックあり
- 一括リネームの取り消し (A5): Undo 基盤あり (移動 Undo 配線済み)
