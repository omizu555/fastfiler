## 3. 非機能要件 (パリティに含む)

| ID | 要件 | 判定方法 |
|---|---|---|
| N-01 | **速度**: System32 級フォルダが瞬時に開く (中核価値 A)。GPUI 版と同等以上 | 実測比較 (同一フォルダの open→描画) |
| N-02 | **メモリ健全性**: タブ/ペイン開閉で生存ペイン数・スレッド・ハンドル・ヒープがベースラインへ戻る | `PANES_ALIVE` 相当の計装を iced 版にも実装 (ADR 0012 の教訓) |
| N-03 | **日本語 IME**: リネーム/新規/パス/検索の全入力欄で変換・未確定表示が機能 | 実機で日本語入力 |
| N-04 | 入力レイテンシ: キーボードナビ・スクロールがもたつかない | 実機体感 + フレーム計測 |
| N-05 | ユーザー設定ファイル互換: themes/*.json・commands.json・hotkeys の既存ファイルがそのまま読める (キー名変更する場合は移行変換を提供) | 既存ファイルで起動 |

## 4. 移行対象外 (作らない / 持たない)

- **不採用 (ADR)**: プラグイン機構 (0003) / 内蔵ターミナル (0004) / メディアプレビュー (0005) / ペイン連動 (0001)。ADR は iced 版でも有効。
- **未実装・凍結 (移行スコープ外、ただし設計余地は残す — 計画書 §拡張余地)**: ペイン内ツリー / インクリメンタルサーチ (#3) / パネルプリセット (#10) / Spring-loaded folder (#17) / 性能計測パネル (#22) / ASCII ツリー UI 配線 (#24) / 部分成功移動ジョブの Undo 記録。

実装規模の目安 (2026-07-02 時点): `fastfiler-domain` 4,794 行 (うちテスト対象の純ロジック多数) /
`fastfiler-gpui` 8,245 行 (app.rs 1,896 + pane.rs 3,883 が中心)。
iced 移行で書き直すのは後者のみ。

## 5. 永続化ファイル一覧 (互換性の境界)

| ファイル | 内容 | 互換方針 |
|---|---|---|
| `%APPDATA%\FastFiler\gpui_session.json` | セッション | 新ファイル名可 (自動移行を推奨) |
| `%APPDATA%\FastFiler\gpui_settings.json` | 設定 | 同上 |
| `%APPDATA%\FastFiler\gpui_hotkeys.json` | ホットキー 18 アクション | 読めること必須 |
| `%APPDATA%\FastFiler\themes\*.json` | カスタムテーマ (37 色キー) | 読めること必須 |
| `%APPDATA%\fastfiler\commands\commands.json` | ユーザーコマンド | 読めること必須 |
| `%APPDATA%\fastfiler\templates\` | 新規ファイルテンプレート | パス維持 |

注意: `FastFiler` / `fastfiler` の大文字小文字ゆれが現存する (cc-rsg Q-004/Q-009)。iced 版で統一するなら移行処理を必ず付ける。

## 6. 既知の内部論点 (再実装時に必ず再登場 — [doc/spec/99-unresolved.md](../spec/99-unresolved.md) より)

- Q-057: テーマ再読込のたびに `Box::leak` でリーク (現状「許容」扱い) → iced 版では leak しない設計にする
- Q-056: IME 未確定文字列 (marked_range) の確定タイミング → iced の IME サポート状況に依存 (計画書リスク台帳参照)
- Q-022: ジョブ本体 panic 時に JobRegistry から unregister されない → 再設計で修正
- Q-019/Q-063: watcher 150ms / セッション保存 800ms のデバウンス値 → 現行値を既定として踏襲
- Q-070: OLE D&D 受信 (HDROP 解析) の入力検証 → 現行の防御的解析を維持
- Q-073: 多重起動防止がウィンドウタイトル一致依存 → 再設計で専用ミューテックス+メッセージへ堅牢化
