# テーマの使い方 (カスタムテーマガイド)

最終更新: 2026-06-07

外観は **テーマ (色) / スタイル (形 = 角丸) / フォント (種類・サイズ)** の 3 軸で、
それぞれ独立に設定画面 (⚙) から変えられる。このファイルはテーマ JSON の書き方と
**全色キーの説明**。スタイル・フォントの操作は [USAGE.md](./USAGE.md) を参照。

## 組み込みプリセット

ダーク / ライト / ミッドナイト の 3 種 (アプリ内蔵、変更不可)。

## カスタムテーマ

置き場所 (初回起動時に自動生成):

```
%APPDATA%\FastFiler\themes\*.json
```

ここにある JSON が起動時に読み込まれ、設定画面のテーマコンボに並ぶ。
初回はサンプル 4 種が生成される (削除しても復活しない):

| ファイル | 内容 |
|---|---|
| `カスタム例.json` | ダーク基準の**全 37 キー入り** — 編集の出発点に最適 |
| `ノルド風.json` | 青灰系ダーク |
| `ハイコントラスト.json` | 黒背景 + 高コントラスト |
| `セピア.json` | 暖色ライト |

### ファイル形式

```json
{
  "name": "マイテーマ",
  "base": "ダーク",
  "colors": {
    "app_bg": "#181818",
    "accent": "#ff8800",
    "sel_bg": "#5a3a00aa"
  }
}
```

| キー | 説明 |
|---|---|
| `name` | テーマ名 (コンボに表示)。プリセットと同名は不可 |
| `base` | 下敷きにするプリセット名 (`ダーク` / `ライト` / `ミッドナイト`)。省略時ダーク |
| `colors` | 上書きする色。**書いたキーだけ** base に重なる (全部書く必要はない) |

- 色は `"#rrggbb"` または `"#rrggbbaa"` (アルファ付き)。`"#rgb"` 短縮形も可
- 編集 → 設定画面の「**再読み込み**」で即反映 (再起動不要)
- 壊れた JSON はスキップされ、設定画面にエラーファイル名が表示される
- 「**テーマフォルダを開く**」ボタンでフォルダをすぐ開ける

## 色キー一覧 (各キーの説明)

### 背景

| キー | 使われる場所 |
|---|---|
| `app_bg` | ウィンドウ全体の下地 |
| `tab_bar_bg` | 左の縦タブバーと最下部フッター |
| `tree_bg` | ワークスペースツリーパネル |
| `pane_bg` | ファイル一覧ペインの地 |
| `input_bg` | テキスト入力欄 (リネーム / 検索 / パス編集) |
| `bar_bg` | ペイン上部のパスバーとペイン下部のステータスバー |
| `header_bg` | 列見出し (名前/更新日時/サイズ/種類) とツリーの見出し |
| `search_bar_bg` | 検索バー (Ctrl+F) — 検索中だと分かる差し色 |
| `row_even` / `row_odd` | 一覧の偶数行 / 奇数行 (しましま) |
| `surface_bg` | メニュー / ダイアログ / ドロップダウンの面 |
| `surface_hover` | その上の軽い hover (検索バーの × など) |
| `button_bg` / `button_hover` | ボタンの地 / hover |
| `separator` | 区切り線 (メニュー / フッター上辺など) |
| `handle_bg` | リサイズハンドル (ペイン境界 / ツリー幅 / タブバー幅) |
| `border_dim` | フォーカスされていないペインの枠線 |

### 選択・インタラクション

| キー | 使われる場所 |
|---|---|
| `sel_bg` | 選択行 / アクティブタブ / 設定の選択中ボタン |
| `sel_cursor_bg` | 選択かつカーソルの行 (一覧で最も明るい行) |
| `cursor_bg` | カーソル行 (未選択時) |
| `hover_bg` | 行・タブのマウス hover |
| `drop_bg` | D&D 中のドロップ先**ペイン**のハイライト |
| `drop_row_bg` | D&D 中のドロップ先**フォルダ行**のハイライト |
| `handle_hover` | リサイズハンドル / 列仕切りの hover |
| `menu_hover` | メニュー項目の hover |
| `danger_bg` / `danger_hover` | 危険系 (上書き確認ボタン / タブ × の hover / ジョブキャンセル) |

### アクセント

| キー | 使われる場所 |
|---|---|
| `accent` | フォーカスペインの枠線 / フォルダのアイコン代替バー / 検索 OK 表示 |
| `accent_file` | ファイルのアイコン代替バー (アイコン取得失敗時) |

### テキスト (明 → 暗の 6 段階)

| キー | 使われる場所 |
|---|---|
| `text_bright` | 最強調 (ダイアログ見出し / hover 時の強調) |
| `text` | 標準の文字色 |
| `text_soft` | やや控えめ (フッター / ボタンラベル) |
| `text_dim` | 補足 (列見出し / セクション見出し / 閉じる ×) |
| `text_faint` | さらに薄い (ショートカット表示 / 検索ヒント) |
| `text_disabled` | 無効状態 (押せないメニュー項目) |

### 半透明 (アルファ付き推奨)

| キー | 使われる場所 |
|---|---|
| `sel_translucent` | テキスト入力欄の選択ハイライト |
| `overlay_bg` | モーダル / 設定画面の背後の暗幕 |

## ヒント

- まず `カスタム例.json` を複製して `name` を変え、気になるキーだけ弄るのが早い
- 似た系統の色はまとめて動かすと破綻しない:
  行まわり (`row_even/odd` `sel_bg` `sel_cursor_bg` `cursor_bg` `hover_bg`)、
  面まわり (`surface_bg` `button_bg` `button_hover` `menu_hover`)
- ライト系を作るときは `base: "ライト"` にするとテキスト 6 段階を流用できる
- 色キーを増やす改修をしたい場合は `theme.rs` の `theme_colors!` マクロ
  ([ARCHITECTURE.md](./ARCHITECTURE.md) の拡張ポイント参照)
