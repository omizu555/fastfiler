# doc フォルダの案内

最終更新: 2026-06-09

FastFiler のドキュメント置き場。**何がどこにあるか**はこのファイルだけ読めば分かる。
プロダクトの中核アイデンティティ (何を目指し何を捨てるか) はリポジトリ直下の
[`/CONTEXT.md`](../CONTEXT.md) を参照。

## 構成

| パス | 内容 | いつ読む / いつ書く |
|---|---|---|
| [USAGE.md](./USAGE.md) | 使い方ガイド (操作・設定の全リファレンス) | 機能の使い方を知りたいとき。**機能を変えたら必ず更新** |
| [THEMES.md](./THEMES.md) | テーマの使い方 — カスタムテーマ JSON と全色キーの説明 | 配色をカスタマイズしたいとき |
| [COMMANDS.md](./COMMANDS.md) | ユーザーコマンドの使い方 — commands.json の全フィールドとプレースホルダ | 右クリックメニューに独自コマンドを足したいとき |
| [COMMANDS-RECIPES.md](./COMMANDS-RECIPES.md) | ユーザーコマンドのコピペ用サンプル集 (エクスプローラ / Claude Code / 圧縮・展開 / ハッシュ表示など) | すぐ使える設定例が欲しいとき |
| [HOTKEYS.md](./HOTKEYS.md) | ホットキーの使い方 — 全アクションの説明とキー割り当ての書式 | キー割り当てを変えたいとき |
| [ARCHITECTURE.md](./ARCHITECTURE.md) | クレート構成 / 状態モデル / リアクティビティ方針 / 拡張ポイント | コードに手を入れる前 |
| [BUILD.md](./BUILD.md) | ビルド & 開発環境 & リリース手順 (ZIP 配布) | 環境構築・リリース時 |
| [IDEAS.md](./IDEAS.md) | 機能アイデアの採否台帳 (やる / やらない の一覧) | 新機能を思いついたとき |
| [adr/](./adr/) | アーキテクチャ意思決定記録。**1 ファイル 1 決定**、過去の本文は書き換えず追記で現状を補足 | 「なぜ持たないのか / なぜこの方式か」を知りたいとき |
| [plan/](./plan/) | 実装計画と作業ログ。**`YYYY-MM-DD-題名.md`** の日付付きファイル | まとまった作業を始めるとき。完了後も記録として残す |
| [spec/](./spec/) | GPUI 版実装の逆生成仕様書 16 章 (cc-rsg、コミット `6513d73` 時点のスナップショット) | 内部挙動をコードレベルで確認したいとき。iced 移行のパリティ参照 |

運用ルール:

- **計画資料は必ず `plan/` に日付付きで作る** (例: `plan/2026-06-07-adr-reconciliation.md`)
- ADR は決定の記録なので削除・書き換えしない。実装と乖離したら
  「追記 (日付)」節かステータス変更 (Superseded) で現状を示す
- 実装ステータスの一覧表 (旧 STATUS.md) は陳腐化が速かったため廃止し、
  下のサマリに簡約した。詳細な「何ができるか」は USAGE.md が一次情報

## 実装状況サマリ

GPUI 移行 ([ADR 0012](./adr/0012-migrate-floem-to-gpui.md)) 後の現況。

**実装済み (要点)** — 詳細は [USAGE.md](./USAGE.md):
縦タブ (列数可変・ロック・D&D 並べ替え) / BSP 分割ペイン / 仮想化一覧 /
ワークスペースツリー (UNC サーバノード含む) / ファイル操作一式 (コピー・移動・削除・
リネーム・テンプレート新規 + 進捗・キャンセル) / Undo (リネーム・移動・ごみ箱 —
全ペイン共通履歴) / 検索 (Ctrl+F、Everything 連携) / D&D (内部・エクスプローラ相互・
右ボタンメニュー) / 右クリックメニュー + ユーザーコマンド + Shift+右クリックの
シェルメニュー / テーマ (プリセット + カスタム JSON) / スタイル / フォント設定 /
ホットキー設定 / セッション永続化 / 多重起動防止 /
矩形 (ラバーバンド) 選択・空白クリック/Esc で選択解除

**未実装・残タスク** (**2026-06-09 時点で下記の機能追加系はしばらく凍結** —
[IDEAS.md](./IDEAS.md) / [plan/2026-06-07-feature-ideas.md](./plan/2026-06-07-feature-ideas.md) の凍結メモ参照):

- 部分成功した移動ジョブの Undo 記録 (domain の per-item 成否が必要 —
  [plan/2026-06-07-adr-reconciliation.md](./plan/2026-06-07-adr-reconciliation.md) §2)
- ペイン内ツリー (ADR 0012 の未対応リスト最後の 1 件)
- ファイル名インクリメンタルサーチ (IDEAS #3 — floem 版から再実装待ち) 〔凍結〕
- パネルプリセット (IDEAS #10) / Spring-loaded folder (IDEAS #17) /
  パフォーマンス計測パネル (IDEAS #22) / ASCII ツリーエクスポートの UI 配線 (IDEAS #24) 〔凍結〕
