# ホットキーの使い方 (カスタマイズガイド)

最終更新: 2026-06-07

ファイル操作系のキー割り当ては全て変更できる。設定ファイルは

```
%APPDATA%\FastFiler\gpui_hotkeys.json
```

初回起動時に既定値で自動生成される (壊れたら削除すれば再生成)。
設定画面 (⚙) の「ホットキー — 設定ファイルを開く」からも開ける。

## 書式

```json
{
  "open": "enter",
  "search": "ctrl+f",
  "new-folder": "ctrl+shift+n"
}
```

- `"アクション名": "combo"` の組。書いていないアクションは既定値のまま
- combo は **修飾キー + キー 1 つ**。修飾は `ctrl+` / `alt+` / `shift+` (組合せ可)
- キーに使えるのは小文字で: `a`〜`z` `0`〜`9` `f1`〜`f12` `enter` `backspace`
  `delete` `tab` `space` `left` `right` `up` `down` `home` `end` `pageup` `pagedown` など
- 大文字や空白は自動で正規化される (`Ctrl + Shift+N` → `ctrl+shift+n`)
- 不正な combo は**そのアクションだけ**既定値に戻る (他には影響しない)
- 同じ combo を複数アクションに割り当てないこと (後に定義された方が勝つ)

**反映**: 設定画面 (⚙) の「ホットキー — 再読み込み」、
背景右クリック「設定 ▸ → ホットキーを再読み込み」、または再起動。

## アクション一覧 (各キーの説明)

| アクション名 | 既定 | 動作 |
|---|---|---|
| `open` | `enter` | 選択を開く (フォルダ = 移動 / ファイル = 既定アプリで開く) |
| `parent` | `backspace` | 親フォルダへ移動 |
| `delete` | `delete` | 選択をごみ箱へ (複数可、`Ctrl+Z` で取り消し可) |
| `rename` | `f2` | 名前の変更 (拡張子手前まで選択された状態で開く) |
| `new-folder` | `f7` | 新しいフォルダを作成 |
| `new-file` | `f8` | 新しい空ファイルを作成 (テンプレートからは右クリック) |
| `refresh` | `f5` | 一覧を最新の情報に更新 |
| `search` | `ctrl+f` | 検索バーを開く (Everything 連携 / 内蔵検索) |
| `undo` | `ctrl+z` | 元に戻す (リネーム / 移動 / ごみ箱送り。全ペイン共通で直近 20 件) |
| `copy` | `ctrl+c` | コピー (エクスプローラ相互運用) |
| `cut` | `ctrl+x` | 切り取り |
| `paste` | `ctrl+v` | 貼り付け (進捗はフッタ表示、`Esc` で中止) |
| `select-all` | `ctrl+a` | 全選択 |
| `back` | `alt+left` | ナビゲーション履歴を戻る (マウス第 4 ボタンでも可) |
| `forward` | `alt+right` | ナビゲーション履歴を進む (マウス第 5 ボタンでも可) |
| `next-pane` | `f6` | フォーカスペインを巡回 (青枠が操作の宛先) |
| `next-tab` | `ctrl+tab` | 次のタブへ |
| `prev-tab` | `ctrl+shift+tab` | 前のタブへ |

## 固定キー (変更不可)

| キー | 動作 |
|---|---|
| `↑` `↓` | カーソル移動 |
| `Shift+↑↓` / `Shift+クリック` | 範囲選択 |
| `Ctrl+クリック` | 個別に選択へ追加 / 除外 |
| `Home` / `End` | 先頭 / 末尾へ (Shift で範囲選択) |
| `Esc` | モーダル/検索を閉じる・実行中ジョブのキャンセル |
| `Enter` / `Esc` (入力欄) | 確定 / キャンセル (IME 対応) |
| `Shift+右クリック` (行) | Windows シェルコンテキストメニュー |
| 中ボタン (タブ) | タブのロック切替 |

入力欄 (リネーム等) 内の編集キー (`Ctrl+A/C/V/X`、`Home/End` 等) も固定。
