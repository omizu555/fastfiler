# FastFiler ユーザーマニュアル 

最終更新: 2026-07-11 (パスバー編集中のクリックを 1 クリック目から有効化 — エクスプローラ準拠)

---

## 1. 画面構成

```
┌──────────┬──────────┬──────────────────────────────┐
│ 縦タブバー │ ワークス  │ ペイン領域 (タブごとの BSP 分割)   │
│           │ ペース    │ ┌─────────────┬─────────────┐ │
│ ＋ [ツリー]│ ツリー    │ │ ペイン A     │ ペイン B     │ │
│ [C: tab1] │ (ドライブ │ │ パスバー      │              │ │
│ [D: tab2] │  + UNC)  │ │ 列見出し      │              │ │
│   …      │          │ │ ファイル一覧  │              │ │
│           │          │ │ フッタ       │              │ │
│           │          │ └─────────────┴─────────────┘ │
└──────────┴──────────┴──────────────────────────────┘
```

- **タブ**: 独立した分割構成・フォルダ・選択状態を持つ作業文脈。
  表示名には場所が必ず付く (ローカル `C: 名前` / ネットワーク `🌐 名前`)。
- **ペイン**: ファイル一覧を表示する矩形。任意に縦横分割できる (BSP)。
- **フォーカスペイン**: キーボード操作とツリークリックの宛先。
- **ワークスペースツリー**: ドライブ + 登録済み UNC share 起点のフォルダツリー。
  タブ切替・フォルダ移動に**自動追従** (展開 + ハイライト + 中央スクロール)。
- **設定**: タブバー上部の「設定」ボタンで設定画面を開く。

リサイズ可能な境界: ペイン間 / ツリー幅 / **タブバー幅** /
**ファイル一覧の列幅** (すべてドラッグ)。

---

## 2. 操作リファレンス

### タブ
| 操作 | 方法 |
|---|---|
| 追加 | `＋` (アクティブペインと同じフォルダで開く) |
| 切替 | タブクリック / `Ctrl+Tab` (次) / `Ctrl+Shift+Tab` (前) |
| 閉じる | タブの `×` (最後の 1 枚は残る) |
| 並べ替え | タブをドラッグして別タブへドロップ |
| **ロック切替** | タブの上で**中ボタン (ホイール) クリック** |
| バー幅変更 | タブバー右端のハンドルをドラッグ (100〜600px) |
| 列数変更 | 設定 → タブバー — 列数 (1〜4、行優先で 1,2 / 3,4 / …) |

タブ名は**一番最初の分割元ペイン**のフォルダ名で固定
(分割中にフォーカスを移しても変わらない。未分割なら移動に追従)。

**ロック中のタブ (🔒 表示)**:
- `×` が出ないため閉じられない (解除は再度中ボタン)
- フォルダ移動 (進入 / ↑ / パス入力 / ツリークリック / 検索ジャンプ) は
  **すべて新しいタブで開き**、ロックタブ自身は動かない
- 戻る / 進む (履歴) は「タブはロックされています」と表示して不動作

### ペイン分割
| 操作 | 方法 |
|---|---|
| 左右 / 上下に分割 | ペイン右上 `↔` / `↕` (ロックタブ内の新ペインはロック継承) |
| ペインを閉じる | ペイン右上 `×` (タブ内最後の 1 枚は残る) |
| サイズ変更 | 分割境界をドラッグ (最小 80px) |
| フォーカス移動 | ペインをクリック / `F6` で巡回 |

### ナビゲーション
| 操作 | 方法 |
|---|---|
| フォルダを開く | ダブルクリック / `Enter` |
| ファイルを開く | ダブルクリック / `Enter` (既定アプリ) |
| 親フォルダへ | `Backspace` / `↑` ボタン |
| 戻る / 進む | **マウス第4/第5ボタン** / `Alt+←` / `Alt+→` (画面ボタンは無し) |
| パス直接入力 | パスバーのパスをクリック → 入力 (`Enter` 移動 / `Esc` 取消)。 \
  入力欄はマウスドラッグで部分選択・コピー可。 \
  存在しないパスを確定すると**移動せず元のフォルダに留まり**、フッタにエラー表示。 \
  編集中に一覧・ツリー・別ペインなどをクリックすると**編集を破棄し、 \
  その操作が 1 クリック目からそのまま効く** (エクスプローラのアドレスバーと同じ) |
| 再読み込み | `F5` (通常は watcher が自動反映) |
| ツリーから開く | ツリーのフォルダ名クリック → フォーカスペインへ |
| ショートカット (.lnk) | **フォルダを指すものは新規タブで開く** (エクスプローラは起動しない)。 \
  ファイルを指すものはターゲットの既定動作 — Office テンプレート (.xltx 等) なら \
  直接ダブルクリックと同じく「テンプレートから新規」でコピーが開く |
| junction / シンボリックリンク | フォルダを指すものは通常フォルダとして開ける (エクスプローラ準拠)。 \
  ファイルを指すものはリンク先のサイズで表示される |

長いパスは `…` で省略表示され、右側のボタンへはみ出さない。

### 一覧の列 (名前 / 更新日時 / サイズ / 種類)
| 操作 | 方法 |
|---|---|
| 並べ替え | 列見出しクリック。再クリックで昇順/降順 (▲▼)。フォルダは常に先頭 |
| **列幅変更** | 見出しの各列の**左端の仕切り**をドラッグ (40〜400px)。 \
  狭くした分だけ名前列が広がる。**ペイン個別**に記憶される |

更新日時はローカル時刻 `YYYY/MM/DD HH:MM`。長いファイル名は `…` 省略。

### 選択
| 操作 | 方法 |
|---|---|
| 単一選択 | クリック / `↑` `↓` `PageUp` `PageDown` `Home` `End` |
| 追加/解除 | `Ctrl+クリック` |
| 範囲選択 (キー) | `Shift+クリック` / `Shift+矢印` など |
| **範囲選択 (矩形)** | 一覧の**空白部分**で左ドラッグ → 矩形に重なる項目を選択 \
  (`Ctrl+ドラッグ`で既存選択に加算) |
| 全選択 | `Ctrl+A` |
| **選択解除** | 一覧の**空白部分をクリック** / `Esc` |

選択中の件数はフッタ右端に表示。watcher の自動更新でも選択は名前で維持される。

**選択済みの行を修飾キーなしで押しても、押した瞬間には選択は崩れない**
(そのまま左ドラッグすれば選択全体を運べる — エクスプローラ準拠)。
ドラッグせずにボタンを離した時点で、その行だけの単一選択になる。

### ファイル操作
| 操作 | 方法 |
|---|---|
| コピー / 切り取り | `Ctrl+C` / `Ctrl+X` (複数可・エクスプローラと相互運用) |
| 貼り付け | `Ctrl+V` (進捗はフッタ・`Esc` か「キャンセル」で中止) |
| 削除 (ごみ箱) | `Delete` (複数可) |
| 名前の変更 | `F2` (拡張子手前まで選択された状態で開く) |
| 新しいフォルダ / ファイル | `F7` / `F8` |
| テンプレートから新規 | 右クリック → 新しいファイル ▸ → テンプレート名 \
  (`%APPDATA%\fastfiler\templates` に置いたファイルが雛形) |
| 元に戻す | `Ctrl+Z` (リネーム / 移動 / ごみ箱送りの取り消し。履歴は全ペイン共通で直近 20 件) |

入力欄は IME (日本語) 対応。`Enter` 実行 / `Esc` キャンセル。
名前に使えない文字 (`\ / : * ? " < > |` と制御文字) はどのダイアログでも
確定できず、フッタに理由が表示される (エクスプローラ準拠。`:` を許すと
新規ファイルは NTFS の代替ストリームを静かに作り、リネームは分かりにくい
OS エラーになる)。

**新しいフォルダ (`F7`) はメモ帳のように複数行で入力できる**。
1 行につき 1 フォルダを一括作成する (空行と行頭行末の空白は無視。重複行は
大文字小文字違いも含めて先勝ちで 1 つに畳む — Windows は区別しないため)。
このダイアログだけ `Enter` は改行で、確定は `OK` ボタンか `Ctrl+Enter`。

**`aaa\iii\uuu` のように `\` (または `/`) 区切りで階層をまとめて作成できる**。
中間フォルダは自動で作られ、既にあっても問題ない (冪等)。作成後のカーソルは
先頭行のトップレベル名へ乗る。
使えない行 (`: * ? " < > |` と制御文字、`.` / `..`・空の階層・末尾が `.` か
空白の名前・`CON` / `NUL` 等の予約デバイス名) が 1 つでもあると確定されず、
フッタに理由が表示される
(`..` や先頭 `\` で現在フォルダの外に作ることはできない)。
作成できなかった名前は入力した表記のままフッタにまとめて表示される。

入力ダイアログ (F2/F7/F8) やパスバー編集の表示中に**別ペインをクリックすると
編集は破棄され**、クリックした操作がそのまま効く (エクスプローラ準拠)。

**同名ファイルがある場合**は確認ダイアログ:
`[上書き] [別名で保存] [キャンセル]` (複数件は一括適用。別名は `名前 (2).拡張子`
の連番)。コピー / 移動 / 貼り付け / D&D すべての経路で共通。

**リモートデスクトップ越しのコピーも貼り付けできる** (エクスプローラ準拠)。
RDP のクリップボードはファイルを実パス (CF_HDROP) ではなく仮想ファイル形式
(`FileGroupDescriptorW` + `FileContents`) で渡すため、この形式にも対応している。
Outlook の添付ファイルのコピー → 貼り付けも同じ仕組みで動く。
仮想ファイルの貼り付けは**常にコピー動作** (相手側で切り取りでも元は消えない —
リモート越しの削除は仕組み上できないため。エクスプローラも同じ)。
進捗・キャンセル・同名衝突ダイアログは通常の貼り付けと共通。

### 右クリックメニュー
- **行の上**: 開く / コピー / 切り取り / 貼り付け / 名前の変更 / 削除 /
  新しいフォルダ / 新しいファイル ▸ / ユーザーコマンド / プロパティ
- **背景**: 貼り付け / 最新の情報に更新 / 新しいフォルダ / 新しいファイル ▸ /
  ユーザーコマンド / プロパティ (フッタの右クリックでも開ける — ファイルが多く
  背景の空きが無いペイン向け)
- **プロパティ** は最下部固定 (エクスプローラ準拠)。行の上はその項目、
  背景は現在フォルダの Windows プロパティダイアログを開く
- **新しいファイル ▸**: テンプレート一覧から選んで新規作成 +
  「テンプレートフォルダを開く」(空ファイルは `F8`)
- `▸` 付きのサブメニューは**クリックで開閉** (hover では開かない。
  再クリックか別項目クリックで切替)
- メニューは常に 1 か所のみ表示 (別ペインをクリック / 右クリックすると閉じる)
- **Shift+右クリック (行)**: Windows 標準のシェルコンテキストメニュー
- 右ボタンを押した瞬間に選択が追従する (選択外の行 → その行だけ選択。
  エクスプローラと同じ — 右ドラッグで何を掴んでいるかが見える)
- ユーザーコマンド: `%APPDATA%\fastfiler\commands\commands.json` に定義した外部コマンド。
  `when` で表示場所を選択 — `file` / `folder` / `selection` (行のみ) /
  `background` (背景のみ) / `drop` (右ドラッグメニュー) / `any` (両方、既定)。
  **書き方の詳細は [COMMANDS.md](./COMMANDS.md)**
- **右ボタンドラッグのメニュー** (ここにコピー / 移動) にも `when: "drop"` の
  ユーザーコマンドが並ぶ ({paths}=ドラッグした項目 / {cwd}=ドロップ先)

### ドラッグ & ドロップ
| 経路 | 動作 |
|---|---|
| ペイン → 別ペイン / フォルダ行 | ドロップ先フォルダへ転送 |
| FastFiler → エクスプローラ | OLE 標準 D&D (送り側として動作) |
| FastFiler → ブラウザ等のアプリ | 添付 (コピー)。元ファイルは消えない (下記参照) |
| エクスプローラ → FastFiler | ペイン (表示フォルダ) / フォルダ行へドロップ |

- **修飾キー**: ドロップ時 `Ctrl` = コピー / `Shift` = 移動 /
  なし = エクスプローラ準拠 (同一ドライブ = 移動、別ドライブ = コピー)
- **右ボタンドラッグ**: ドロップ時に「ここにコピー / ここに移動 / キャンセル」を
  選択 (アプリ内)。エクスプローラへは標準メニューが出る
- 選択中の行をドラッグすると選択全体を運ぶ
- **元ファイルの削除は安全側**: 外部アプリへ送ったとき元を削除するのは、
  ドロップ先が「移動を実行した」と明示 (`PerformedDropEffect=MOVE`) した場合だけ。
  ブラウザ (Chrome 系 / Firefox) の AI チャット等は添付してもこれを通知しないため、
  **元は削除されずコピー (添付) 扱い**になる。実際に削除する場合も
  完全削除ではなく**ゴミ箱送り** (`Ctrl+Z` 非対応だがゴミ箱から復元可) とする。

### 検索 (`Ctrl+F`)
1. `Ctrl+F` で検索バーが開く (**ファイル一覧は表示されたまま**)
2. パターンを入力して `Enter` で実行 → 結果リストに切替
3. 結果をダブルクリック: フォルダ → 開く / ファイル → 親を開いて選択
4. `Esc` / `×` で閉じて一覧へ戻る (実行中の検索は閉じた時点で停止する)

検索エンジンは Everything (HTTP) が応答すればそれを使い、不達なら内蔵検索へ
自動フォールバック。Everything のポートは設定画面で変更できる。

## 3. 設定画面 (タブバー上部の「設定」ボタン)

| 項目 | 内容 |
|---|---|
| テーマ | プリセット (ダーク / ライト / ミッドナイト) + `themes\*.json` のカスタムテーマ。「テーマを再読込」付き。即適用 |
| スタイル | 形状プリセット: モダン (角丸 = 従来) / シャープ (角丸なし) / ソフト (丸め強め)。色 (テーマ) とは独立。即適用 |
| フォント | **絞り込み入力 + 候補ボタン方式** — フォント名の一部 (例: yu / gothic / 明朝) を打つと一致候補が最大 8 件のボタンで出る。クリックで選択 (再起動後に反映)。サイズはスライダで行高に即時追従 |
| レンダラ | **省メモリ (既定)** = メモリ約 1/10・起動高速 / GPU (wgpu/DX12) = 大画面で描画が重い場合の選択肢。再起動後に反映 |
| タブバー | タブの列数 1〜4 / 「ツリー」トグルボタンの表示・非表示 |
| ホットキー | 設定ファイル (hotkeys.json) を開く / 再読み込み |
| フォルダ | テンプレート / ユーザーコマンドのフォルダをペインで開く |
| 検索 | Everything HTTP サーバのポート (既定 80)。入力で自動保存 |

閉じる: 「× 閉じる」 / `Esc`。
設定の保存先: `%APPDATA%\FastFiler\settings.json` (即時保存。
旧 gpui_/iced_ 接頭辞のファイルからは初回起動時に自動移行)。

### カスタマイズの詳細ガイド

| やりたいこと | ガイド |
|---|---|
| 配色を変える / 自作テーマ JSON を書く (全色キーの説明) | [THEMES.md](./THEMES.md) |
| 右クリックメニューに独自コマンドを足す (commands.json) | [COMMANDS.md](./COMMANDS.md) |
| キー割り当てを変える (hotkeys.json、全アクションの説明) | [HOTKEYS.md](./HOTKEYS.md) |

概要だけ:

- **テーマ**: `%APPDATA%\FastFiler\themes\*.json` (初回にサンプル 4 種生成)。
  `base` のプリセットに `colors` の hex を上書きする形式。設定画面の「再読み込み」で即反映
- **ユーザーコマンド**: `%APPDATA%\fastfiler\commands\commands.json`。
  `{path}` `{cwd}` 等のプレースホルダ付きで任意の外部コマンドをメニューに追加
- **ホットキー**: `%APPDATA%\FastFiler\hotkeys.json`。`{ "action": "combo" }` 形式で
  18 アクションを変更可。矢印などの移動系とモーダル内 Enter/Esc は固定

## 4. セッション復元

以下が自動保存され、次回起動時に復元される
(`%APPDATA%\FastFiler\session.json`):

- タブ一覧 (並び順・**ロック状態**) とアクティブタブ
- 各タブの分割構成 (方向・比率) と各ペインのフォルダ・フォーカス・**列幅**
- ワークスペースツリーの表示状態・幅・登録済み UNC share
- タブバーの幅 / ウィンドウの位置とサイズ・最大化状態

保存は変更の 800ms 後 (デバウンス) とアプリ終了時。

---

## 5. その他の挙動

- **多重起動防止**: 二重起動すると既存ウィンドウが前面化する。
- **UNC 自動登録**: `\\server\share\…` をペインで開くとツリーに自動登録される。
  サーバノードの右クリックで登録解除。
- **ツリー追従**: タブ切替やフォルダ移動でツリーが現在地まで自動展開・選択表示。

## 6. トラブルシューティング

- **一覧が更新されない**: `F5`。ネットワークドライブは watcher が効かない場合あり。
- **貼り付けが無効 (淡色)**: クリップボードにファイルが無い状態
  (RDP / Outlook の仮想ファイルはファイル扱い — §2 参照)。
- **検索が「検索エラー」になる**: Everything 未起動またはポート不一致。
  設定画面でポートを確認 (内蔵検索へは自動フォールバックする)。
- **セッションを初期化したい**: アプリ終了後に
  `%APPDATA%\FastFiler\session.json` を削除。
- **設定 / ホットキーを初期化したい**: 同フォルダの `settings.json` /
  `hotkeys.json` を削除 (次回起動時に既定値で再生成)。
