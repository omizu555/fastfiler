## 1. はじめに

リリースビルドを起動すると、初回はホームフォルダ (`C:\Users\<あなた>`) を 1 タブだけ開いた状態で立ち上がります。2 回目以降は前回のセッション (タブ構成・パス・分割比率・パネル配置・ホットキー) を `settings.ron` から自動復元します。

リセットしたいときはアプリ終了後に `%APPDATA%\FastFiler\` フォルダごと削除してください。

## 2. 画面構成と用語

```
┌───────────────────────────────────────────────────────────┐
│ タイトルバー (Windows 標準)                                │
├──────────┬────────────────────────────────────────────────┤
│          │  パンくず ↑ ✎ … (ペインツールバー)              │
│ 縦タブ   ├────────────────────────────────────────────────┤
│ パネル   │                                                │
│          │   メインペイン (ファイル一覧 / ペイン内ツリー🚧) │
│ (ワーク  │                                                │
│ スペース │                                                │
│ ツリー🚧)│                                                │
│          │                                                │
├──────────┴────────────────────────────────────────────────┤
│ ⚡FastFiler                                          ⚙    │
└───────────────────────────────────────────────────────────┘
```

用語は [`/CONTEXT.md`](../CONTEXT.md) の定義が正。要点だけ:

| 名称 | 説明 |
|------|------|
| **タブ** | 独自のペイン分割構成と表示中フォルダを持つ作業文脈 |
| **ペイン** | タブの中の矩形領域。任意の縦/横分割でネスト可能 (BSP) |
| **フォーカスペイン** | 直近で操作したペイン。ホットキー / ツリークリックの宛先 |
| **ワークスペースツリー** 🚧 | ドライブ起点のグローバルツリーパネル |
| **ペイン内ツリー** 🚧 | ペイン cwd 起点の子ツリー (フォルダのみ) |
| **ドックスロット** | パネルを置ける 5 ヶ所 (`left/right/top/bottom/hidden`)。1 スロット 1 パネル |

## 4. ファイル / フォルダ操作

### 4.1 基本操作 (移動 / 選択)

| 操作 | キー / マウス |
|---|---|
| 開く / 入る | ダブルクリック / `Enter` |
| 親フォルダへ | `Backspace` または ペインツールバー `↑` |
| 再読込 | `F5` |
| 全選択 | `Ctrl+A` |
| 範囲選択 | `Shift+クリック` / `Shift+↑/↓` |
| 追加選択 | `Ctrl+クリック` |
| 矢印で移動 | `↑/↓/←/→` |

ファイルリストは **行高 28px の仮想スクロール** で動作するので、`C:\Windows\System32` のような数万件フォルダでも瞬時に開きます。

### 4.2 コピー / 切り取り / 貼り付け / リネーム / 削除

| 操作 | キー |
|---|---|
| コピー | `Ctrl+C` |
| 切り取り | `Ctrl+X` |
| 貼り付け | `Ctrl+V` |
| 名前の変更 | `F2` |
| 新規フォルダ | `Ctrl+Shift+N` |
| 新規ファイル | 右クリック → **新規ファイル** サブメニュー |
| ゴミ箱へ送る | `Delete` |
| 完全削除 (戻せません) | `Shift+Delete` |
| Undo | `Ctrl+Z` |

`Delete` は OS のごみ箱経由 (`SHFileOperationW`) なので誤操作時もリカバリ可。

> リネーム / 新規フォルダ / 新規ファイルの入力ダイアログは、画面中央に小さな
> ポップアップとして表示されます。`Enter` で確定、`Esc` または背景クリックで閉じます。

#### Undo の対象

[ADR 0006](./adr/0006-undo-scope.md) により、Undo (`Ctrl+Z`) は次の 3 種のみ対象です:

- リネーム
- 移動
- ゴミ箱送り

**コピーは対象外** (Undo するとコピー後の編集を破壊するリスクがあるため)。
履歴は in-memory N=20、起動間で保持しません。

#### 4.2.1 新規ファイル (テンプレート)

ペイン余白で右クリック → **新規ファイル** から、ユーザー定義テンプレートを基にファイルを作成できます。

**ユーザー定義テンプレートの追加方法**

`%APPDATA%\fastfiler\templates` フォルダにテンプレートにしたいファイルを置いてください。サブメニューに自動的にファイル名が並びます (サブメニュー最下部の **「テンプレートフォルダを開く」** からも開けます)。

- テンプレを選択するとカレントフォルダに同名でコピーされ、同名がある場合は ` (2)`, ` (3)` … が自動付与されます。
- リネームしたい場合は作成後に `F2` を押してください。
- テンプレフォルダが空のときは **「(テンプレートがありません)」** と表示されます。
- サブメニュー下部の **「空ファイルを作成…」** から従来通り任意のファイル名で空ファイルを作成できます。

> **💡 エクスプローラとのクリップボード連携**
> `Ctrl+C` / `Ctrl+X` を実行すると Windows クリップボードにもファイルパスが書き込まれます。FastFiler でコピー / 切り取りした後、エクスプローラや他のアプリで **`Ctrl+V` して貼り付け** ることができます。切り取りの場合、エクスプローラが貼り付け完了時に元ファイルを自動削除します。

### 4.3 ドラッグ & ドロップ (左ボタン)

#### 内部 D&D (FastFiler 内ペイン同士)

ペインの行を左ボタンで掴み、別ペインのフォルダへドロップします。

| 状況 | 既定動作 | `Ctrl` 押下時 | `Shift` 押下時 |
|---|---|---|---|
| 同一ボリューム間 | **移動** | コピー | 移動 |
| 別ボリューム間 | **コピー** | コピー | 移動 |

- `Ctrl+Shift` 同時押しは `Ctrl` (= コピー) を優先します (安全側)。
- 修飾なしの判定は **全 source が dest と同じボリューム** の場合のみ移動、それ以外は全件コピーします (混在ボリュームは一括コピー)。
- 移動時、`src.parent() == dest_dir` のアイテム (= 同じフォルダへの移動) は無視されます。Ctrl コピーは同名衝突を避けるため `(2)` 等が付いて複製されます。
- 大量操作 (件数 ≥ 100 または 合計 ≥ 50MB) は進捗ダイアログ経由で実行され、**Undo 対象外**です。
- ドロップ先の解決優先順は **フォルダ行 → パンくずセグメント → ペイン背景 (現在フォルダ)** です。

#### 外部 D&D (エクスプローラ → FastFiler / FastFiler → エクスプローラ)

| 方向 | 状態 | 概要 |
|---|---|---|
| FastFiler → エクスプローラ | ✅ 実装済 (送信側) | ファイル/フォルダをドラッグして window 外に出すと OLE D&D に切り替わり、エクスプローラや他アプリへ Copy/Move でドロップ可。`Ctrl` で Copy、無修飾で Move (Move は既定で永続削除、Explorer 互換)。 |
| エクスプローラ → FastFiler | ✅ 実装済 (受信側) | エクスプローラ等から FastFiler のペインへドロップして取り込み可。ペイン上にホバーすると背景がハイライトされます。修飾キーは内部 D&D と完全統一 (`Ctrl=Copy` / `Shift=Move` / 無修飾=同ボリュームなら Move / 異ボリュームは安全側 Copy)。閾値超え (≥100 件 or ≥50MB) は進捗ダイアログ経由 (Undo 不可)、それ未満は同期実行 (Move のみ Undo 対応)。 |

挙動メモ:

- window root から `PointerLeave` が発火した瞬間に `DoDragDrop` を起動します (modal loop)。
- 外部ドロップが完了したら、結果に関わらず元ペインを即時 reload します (Explorer がシェル経由で source を削除するケースに対応)。
- `OleInitialize` が失敗した環境では外部 D&D 送信は無効化されますが、内部 D&D は動作します。

クリップボード経由の連携も従来通り使えます:

| 方法 | 操作 |
|---|---|
| クリップボード経由 | FastFiler で `Ctrl+C` / `Ctrl+X` → エクスプローラ等で `Ctrl+V` (双方向) |

> `Shift+クリック` (動かさない) は従来通り**範囲選択**です。

#### Spring-loaded folder

D&D 中にツリーやフォルダ行の上で **0.7 秒ホバー** すると自動で開きます。

- **ペイン内のフォルダ行**: そのフォルダへ `cd` (戻るスタックに記録、`Alt+←` で戻れる)
- **ワークスペースツリーのノード**: そのノードを **展開** (cd はしない)

ホバーが外れたり、ドロップ完了 / Esc / キャンセルではタイマーがリセットされます。
内部 D&D (左ボタン / 右ボタン両方) で動作します。外部 OLE 受信中は今のところ対象外です。

#### OLE D&D Effect 細粒度制御

内部 D&D は上表のとおり `Ctrl` / `Shift` / ボリューム判定で Move / Copy を切り替えます。外部 D&D 送信 (FastFiler → エクスプローラ) は `Ctrl` で Copy、それ以外は Move を推奨ヒントとしてターゲットに渡します。外部 D&D 受信 (エクスプローラ → FastFiler) は内部 D&D とまったく同じ判定 (`Ctrl=Copy` / `Shift=Move` / 無修飾はボリューム判定) で Effect が決まります。

### 4.4 右ボタン D&D メニュー

ファイルを **右ボタン** で掴んでドラッグし、ドロップ位置で離すと、コピー / 移動を選ぶメニューが表示されます。

- **📁 ここに移動** ── 移動を実行 (`Undo` 対象)
- **📄 ここにコピー** ── コピーを実行
- **✖ キャンセル** ── 何もせず閉じる

対応シーン:

- ペイン間の右ボタン D&D (内部)
- エクスプローラ → FastFiler の右ボタン D&D (外部受信)

挙動:

- 同一フォルダにドロップした場合はメニューを出さず無視します (左ボタン D&D と同じ)。
- 右ボタンドラッグ中の `Ctrl` / `Shift` は無視されます (メニュー選択が最終決定)。
- Esc / メニュー外クリック / 「キャンセル」選択ではファイル操作は実行されません。
- FastFiler → エクスプローラ送信側の右ボタン D&D は未実装です (左ボタンのみ対応)。

実装の詳細は [ADR 0010](./adr/0010-right-button-drag-and-drop-scope.md) / [ADR 0011](./adr/0011-right-button-drop-detection-via-win32-subclass.md) を参照。

### 4.5 コンテキストメニュー / プロパティ

ファイル / フォルダを **右クリック** すると、FastFiler が完全制御する**軽量メニュー**が表示されます。

- 開く / 親フォルダ / 切り取り / コピー / 貼り付け / 名前の変更 / 削除
- **新規ファイル** サブメニュー
- **ユーザー コマンド** (`commands.json` で定義した外部コマンド — §11)
- **エクスプローラで表示** ── Windows 標準のエクスプローラを起動
- **プロパティ** ── サイズ・更新日時・属性を表示
- 末尾の **Windows メニュー…** 🚧 — Shift+右クリック相当

#### Shift+右クリックで Windows シェル拡張メニュー 🚧

`Shift+右クリック` を押すと、Windows エクスプローラと**同等の `IContextMenu` メニュー**が表示され、7-Zip / Git GUI / クラウド同期などのシェル拡張動詞が並びます ([ADR 0007](./adr/0007-shell-context-menu-shift-only.md))。

通常右クリックは常に FastFiler の軽量メニューを保ち、シェル拡張が必要なときだけ Shift で「Windows 標準に逃げる」設計です。

#### 4.5.1 `.iso` / `.img` / `.vhd` / `.vhdx` をダブルクリック

ディスクイメージをダブルクリックすると、Windows エクスプローラと同じ **「マウント」** 動作が走ります (`ShellExecuteW` の `mount` 動詞)。マウント解除はエクスプローラの右クリックメニュー「取り出し」から行ってください。

### 4.6 プログレスダイアログ 🚧

コピー / 移動 / 削除でファイル件数や総バイト数が一定を超えると、進捗バー + 件数 / バイト数 + `✕` (キャンセル) のダイアログが表示されます。`fastfiler-domain::file_jobs` の `JobRegistry` をフロントの UI に接続して実装します。

## 5. ナビゲーション

### 5.1 パンくず

ペインツールバーの中央が **パンくず** です。

- 各セグメントクリックでその階層へジャンプ
- セグメントへ **ファイルを D&D** で移動 (Ctrl でコピー)
- パスが長くて隠れる場合は **末尾 (現在フォルダ) が右側に残る** ように自動スクロール
- 右端の `✎` (鉛筆) クリックでパス入力モードへ

### 5.2 アドレス入力 (`Ctrl+L`)

`Ctrl+L` または パンくず右端の `✎` でパス入力モードに切替。

- パス文字列を直接編集
- `Tab` で部分入力からの **フォルダ補完**
- `Esc` でパンくず表示に戻る
- 既存テキストは自動選択されるので、`Ctrl+C` で **そのままコピー** 可能

### 5.3 PC ビュー (ドライブ一覧)

ドライブ直下 (例: `C:\`) でさらに `Backspace` (または `↑` ボタン) を押すと **💻 PC ビュー** に遷移し、全ドライブをカード一覧表示します。クリックで該当ドライブへ移動。

### 5.4 ネットワークドライブ / UNC

#### ドライブ種別の認識

| 種別 | アイコン | 例 |
|---|---|---|
| 固定 (fixed) | 💽 | C:, D: |
| ネットワーク (network) | 🌐 | Z: → `\\server\share` |
| リムーバブル (removable) | 💾 | USB メモリ |
| CD/DVD (cdrom) | 💿 | 光学ドライブ |
| RAM ディスク (ram) | ⚡ | 仮想ドライブ |

#### UNC パスでの直接アクセス

アドレスバーに `\\server\share[\sub...]` を入力して `Enter` で直接開けます。マップしていなくても利用可。

- パンくず分割: `\\server\share` を 1 ルートとして扱い、サブフォルダがチェーン化
- 親フォルダ移動: `\\server\share\sub` → `\\server\share` → ドライブ一覧

#### ワークスペースツリーへの UNC 自動登録

UNC を開くと `\\server\share` がワークスペースツリーの **🖥️ サーバノード** 配下に自動登録され、次回ワンクリックで再アクセスできます。

- **グルーピング**: 同じサーバの share は 1 つの 🖥️ サーバノード配下にまとめる
- **並び順**: ローカルドライブ (A→Z) → サーバ (A→Z、各サーバ内 share も A→Z)
- **削除**:
  - share を右クリック → 「ツリーから削除」
  - 🖥️ サーバを右クリック → 「ツリーから削除 (サーバごと)」 (配下の share をまとめて除去)
- **永続化**: `settings.ron` の `tree_unc_shares` に保存。次回起動時にサーバが応答しなくてもツリーは壊れません (サーバノードは仮想ルートで、子の展開はクリック時に試行)
- **対応形式**: `\\server\share` と `\\?\UNC\server\share` の両方を同一視 (内部で正規化)
- **サーバノードの挙動**: 仮想ルートなので名前クリックでナビゲートはしません (share をクリックして開いてください)

## 6. 縦タブ

### 6.1 開く / 閉じる / 切替

| 操作 | キー / UI |
|---|---|
| 新しいタブ | `Ctrl+T` または タブパネル上部の「＋ 新規」 |
| タブを閉じる | `Ctrl+W` または タブ右の `×` |
| タブ切替 (順) | `Ctrl+Tab` / `Ctrl+PageDown` |
| タブ切替 (逆) | `Ctrl+Shift+Tab` / `Ctrl+PageUp` |
| 直接ジャンプ | `Ctrl+1`〜`Ctrl+8` |
| 末尾タブへ | `Ctrl+9` |

タブ名は **現在開いているフォルダ名** が自動表示されます。フルパスはホバー時のツールチップで確認可。

### 6.2 並べ替え

タブをドラッグすると半透明になり、ドロップ位置に青いインジケータが表示されます。ドロップで順序が確定し、再起動後も保持されます。

### 6.3 列数の変更

`Ctrl+,` →「基本」タブ → **タブ列数** で **1〜4** を指定。即時反映。

> 5 列以上は縦方向の作業領域が削られるため上限を 4 にしています。

### 6.4 タブのロック (中クリック) 🚧

タブを **マウス中ボタン (ホイール) クリック** でロック / 解除。

- ロック中はタブの境界に **黄色のライン** が出ます
- `×` ボタンの位置に **🔒 アイコン** が表示され、クリックで解除可能
- ロック中タブは `Ctrl+W` や右上 `×` を押しても閉じません (誤クローズ防止)

### 6.5 タブのアイコン / ドライブ表示 🚧

タブ名の先頭にパス種別が表示されます。

| パス | 表示例 |
|---|---|
| ドライブ配下 (`C:\…`) | `C:` のドライブレターを文字で表示 |
| UNC (`\\server\share\…`) | 🌐 アイコン |
| その他 (PC ビュー等) | アイコンなし |

## 7. ペインとパネル配置

### 7.1 ペイン分割

各ペインのツールバーから:

- **┃ 縦分割** ── 左右に 2 ペイン
- **━ 横分割** ── 上下に 2 ペイン
- **× 閉じる** ── このペインを閉じる

中央の分割線をドラッグでサイズ調整。比率はタブと共に保存されます。

### 7.2 フォーカスペイン

直近で操作したペインが「フォーカスペイン」として記憶され、青い inset 枠で示されます。

- 切替タイミング: クリック / `Tab` / キー操作 / フォルダ移動
- タブ切替時は、そのタブで前回フォーカスしていたペインが自動復元
- ワークスペースツリーや「親フォルダへ」「アドレス入力」などの宛先になります

> **連動 Red/Blue は廃止されました** ([ADR 0001](./adr/0001-remove-pane-linking.md))。
> 「複数フォルダを同時に操作したい」場合はタブ + 任意分割ペインで実現してください。

### 7.3 ワークスペースツリー 🚧

ドライブ起点のグローバルなツリーパネル。

- **`Ctrl+Shift+E`**: 3 状態サイクル — 非表示 → 表示+フォーカス → 非表示。表示中で非フォーカスなら **フォーカスを取りに行く**
- ローカルドライブ (C:\, D:\, …) と登録済み UNC を複数ルートで並列表示
- フォルダクリックで **フォーカスペイン** にその場所を開く
- **キーボード操作** (ツリーにフォーカスがある時):
  - `↑/↓`: 可視ノード列を移動
  - `→`: 折畳中なら展開 / 展開中なら最初の子へ (VSCode 流)
  - `←`: 展開中なら折畳 / 折畳中なら親へ
  - `Home/End`: 先頭 / 末尾へジャンプ
  - `Enter`: フォーカスペインにその場所を開く
  - `Esc`: フォーカスを解除
- フォーカス行は背景色付き (アクティブ=アクセント色、非アクティブ=ホバー色)
- **フォーカスペイン追従**: フォーカス中ペインの cd に追従して祖先を自動展開、ノードを画面内にスクロール
- パネル端をドラッグでサイズ変更

### 7.4 ペイン内ツリー 🚧

各ペインのツールバー 🌲 ボタンで **ツリー表示** に切替。`📋` でリストに戻ります。

- ペイン内ツリーは **そのペインの path** に追従します (= 列挙対象を起点とした子ツリー)
- **フォルダのみ表示** (ワークスペースツリーと操作モデルを統一)

### 7.5 ドックスロット (パネル配置) 🚧

タブパネル / ワークスペースツリーパネルは `左 / 右 / 上 / 下 / 非表示` の **5 ヶ所** にドックできます ([ADR 0002](./adr/0002-dock-slot-single-panel.md))。

| ボタン | 動作 |
|---|---|
| `◧` | 左にドック |
| `◨` | 右にドック |
| `⬒` | 上にドック |
| `⬓` | 下にドック |
| `✕` | 非表示 |

**各スロットには常に 1 パネルだけ**が入ります (同位置への積み重ね・並列表示はサポートしません)。すでに別パネルが入っている位置を選ぶと、既存パネルは `hidden` に追い出されます。

#### サイズ変更

- 左 / 右 dock: パネルの内側端をドラッグで横サイズ
- 上 / 下 dock: パネルの内側端をドラッグで縦サイズ
- 140〜1200px の範囲で記憶、再起動後も保持

### 7.6 パネルプリセット 🚧

「コーディング用 / バックアップ用」のように、**レイアウト + 開いているタブ**をまとめて保存・呼出する機能。設定ダイアログの「プリセット管理」タブから操作します。

## 8. 検索

### 8.1 内蔵検索

`Ctrl+F` で検索パネルを開きます。

- **substring**: 含まれる文字列で検索 (既定、大文字小文字区別なし)
- **regex**: 正規表現
- ストリーミング表示で大量ヒットでも結果が即座に流れます
- 結果行をダブルクリックで該当フォルダへジャンプ
- もう一度 `Ctrl+F` で閉じる、`Esc` でも閉じる

### 8.2 ペイン内インクリメンタルサーチ

ペインにフォーカスして文字キーを連打すると、**先頭一致でハイライト**してジャンプします。一定時間 (300ms) 入力が無ければバッファクリア。`Ctrl+F` (再帰検索) とは別物として併用できます。

### 8.3 Everything 連携

[Everything (voidtools)](https://www.voidtools.com/) の HTTP API と連携し、爆速検索が可能です。

#### セットアップ

1. Everything をインストールして起動
2. `Tools` → `Options` → `HTTP Server` を開き **Enable HTTP Server** をチェック (既定ポート 80)
3. FastFiler の `Ctrl+,` →「検索」タブ
4. **検索バックエンド** を `Everything HTTP` に変更、ポートを Everything と一致させる
5. `接続テスト` で ✅ なら OK

#### 動作

- 検索開始時に Everything HTTP API へクエリを投げて即時表示
- 失敗時は内蔵検索 (再帰列挙) に自動フォールバック (オレンジ表示)
- 「現在のフォルダ以下に限定」を ON にすると `path:"…"` で絞り込み

### 8.4 ペイン単位の検索状態

- 検索パネルの **開閉状態 / クエリ / オプション** はペイン単位で保持
- タブ切替で:
  - 元タブの検索パネルはそのまま残る
  - 切替先で未起動なら表示されない
  - 元タブに戻るとクエリも復元

> **USN ジャーナル監視は採用しません**。Everything HTTP 連携で同等の体験が得られるため
> ([STATUS.md §3](./STATUS.md))。

## 10. 外部ターミナル / 外部アプリ起動

FastFiler は**内蔵ターミナルを持ちません** ([ADR 0004](./adr/0004-no-builtin-terminal.md))。
カレントペインで PowerShell や Windows Terminal を開きたい場合は、§11 の
**ユーザーコマンド (`commands.json`)** から外部プロセスとして起動します。

サンプル (`commands.json.sample` に既定で含まれます):

```jsonc
{
  "id": "wt-here",
  "label": "ここで Windows Terminal",
  "icon": "🖥️",
  "exec": "wt.exe",
  "args": ["-d", "{cwd}"],
  "when": "background"
}
```

## 11. ユーザーコマンド (`commands.json`)

`%APPDATA%\FastFiler\commands\commands.json` に JSON 配列を書くだけで、右クリックメニューに任意の外部コマンドを追加できます。VSCode で開く / 7-Zip で圧縮 / ここで PowerShell — などを自分専用に整備可能です。

[ADR 0003](./adr/0003-remove-plugin-system.md) により、FastFiler 自体に対する**ユーザー拡張点はこの仕組みが正式な経路**です (JS / WASM プラグイン機構は持ちません)。

### 11.1 設置手順

1. 設定 (`Ctrl+,`) → 基本タブ → 「ユーザー コマンド」の **📁 コマンド フォルダを開く**
2. 同フォルダの `commands.json.sample` を開いて中身をコピー
3. 同フォルダに `commands.json` を新規作成して貼り付け、編集
4. 設定タブの **🔄 再読込** ボタンで反映 (起動時にも自動ロード)

### 11.2 スキーマ

```jsonc
[
  {
    "id": "vscode",                 // 必須・一意
    "label": "VSCode で開く",       // 必須 (メニュー表示)
    "icon": "🆚",                    // 任意 (絵文字 1 文字)
    "exec": "code",                 // 必須 (PATH 解決可)
    "args": ["{path}"],             // 任意
    "cwd": "{parent}",              // 任意 (既定: 現在ペイン)
    "when": "any",                  // file|folder|any|background (既定 any)
    "extensions": [".md"],          // 任意 (when=file のとき AND 条件)
    "submenu": "開く",              // 任意 (グループ化サブメニュー)
    "shell": false,                 // true なら cmd /c 経由
    "hidden": false                 // true で一時無効化
  }
]
```

### 11.3 プレースホルダ

| 変数 | 展開 |
|---|---|
| `{path}` | 選択 1 件目のフルパス |
| `{paths}` | 全選択 (空白区切り、空白を含むものは自動でクオート) |
| `{name}` | basename (拡張子付) |
| `{stem}` | basename (拡張子なし) |
| `{ext}` | `.xxx` 形式の拡張子 |
| `{parent}` | 親フォルダ |
| `{cwd}` | 現在ペインのパス |
| `{count}` | 選択件数 |

### 11.4 `when` (表示条件)

| 値 | 表示タイミング |
|---|---|
| `file` | 選択がすべてファイル (1 件以上) |
| `folder` | 選択がすべてフォルダ |
| `any` (既定) | 1 件以上選択 (ファイル / フォルダ問わず) |
| `background` | 選択 0 件 (空白部の右クリック) |

`extensions` は `when=file` と組合わせて使い、選択全件が指定拡張子に一致するときのみ表示されます。

### 11.5 実行例

| 例 | 設定 |
|---|---|
| 7-Zip 圧縮 | `exec: "7z.exe"`, `args: ["a", "{parent}\\{stem}.7z", "{paths}"]`, `submenu: "圧縮"` |
| 7-Zip 展開 | `exec: "7z.exe"`, `args: ["x", "{path}", "-o{parent}", "-y"]`, `when: "file"`, `extensions: [".zip", ".7z"]` |
| ここで PowerShell | `exec: "powershell.exe"`, `args: ["-NoExit", "-Command", "Set-Location -LiteralPath '{cwd}'"]`, `when: "background"` |
| ImageMagick 縮小 | `exec: "magick"`, `args: ["{path}", "-resize", "50%", "{parent}\\{stem}_half{ext}"]`, `when: "file"`, `extensions: [".jpg", ".png"]` |

### 11.6 注意

- `commands.json` 本体には **コメント (`//`) を書けません** (標準 JSON 仕様)。サンプルのコメントは削除してください
- `exec` のフルパスにバックスラッシュを書く際は `\\` でエスケープ
- `shell: true` のときは内部で `cmd /c "<exec> <args>"` に組み立て直すため、引数のクオートは Rust 側が自動で行います
- 実行は **非同期**。標準出力 / 標準エラーは現状取得していません
- 失敗時はダイアログで通知 (ファイル未存在など spawn エラー)

## 15. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 起動直後に終了する | `fastfiler.log` を確認。`settings.ron` のパース失敗が原因なら同フォルダを削除 |
| ウインドウが画面外に出る | `settings.ron` の `window_x` / `window_y` を編集 or 削除 |
| Everything 検索結果が出ない | Everything の HTTP Server が起動 + ポート (既定 80) が設定と一致しているか |
| シェル拡張メニューが出ない | 通常右クリックではなく **Shift+右クリック** を使う ([ADR 0007](./adr/0007-shell-context-menu-shift-only.md)) |
| 0xc0000005 等のクラッシュ | 操作手順とログを Issue へ |
