## 1. 画面構成

```
┌──────────┬──────────┬──────────────────────────────┐
│ 縦タブバー │ ワークス  │ ペイン領域 (タブごとの BSP 分割)   │
│           │ ペース    │ ┌─────────────┬─────────────┐ │
│ ＋新規タブ │ ツリー    │ │ ペイン A     │ ペイン B     │ │
│ [タブ1]   │ (ドライブ │ │ パスバー      │              │ │
│ [タブ2]   │  起点)   │ │ 列見出し      │              │ │
│   …      │          │ │ ファイル一覧  │              │ │
│           │          │ │ フッタ       │              │ │
│ live panes│          │ └─────────────┴─────────────┘ │
└──────────┴──────────┴──────────────────────────────┘
```

- **タブ**: それぞれが独立した分割構成・フォルダ・選択状態を持つ作業文脈。
- **ペイン**: ファイル一覧を表示する矩形。任意に縦横分割できる (BSP)。
- **フォーカスペイン**: 青枠のペイン。キーボード操作とツリークリックの宛先。
- **ワークスペースツリー**: ドライブ起点のフォルダツリー。クリックで
  フォーカスペインにそのフォルダを開く。「ツリー」ボタンで表示切替。
- **live panes**: 生存ペイン数のデバッグ表示。タブ/ペインを閉じると減る
  (メモリ健全性の確認用)。

各境界 (ペイン間 / ツリー) はドラッグでリサイズ可能。

## 2. 操作リファレンス

### タブ
| 操作 | 方法 |
|---|---|
| 追加 | `＋ 新規タブ` (アクティブペインと同じフォルダで開く) |
| 切替 | タブクリック / `Ctrl+Tab` (次) / `Ctrl+Shift+Tab` (前) |
| 閉じる | タブの `×` (最後の 1 枚は残る) |

### ペイン分割
| 操作 | 方法 |
|---|---|
| 左右に分割 | ペイン右上 `↔` |
| 上下に分割 | ペイン右上 `↕` |
| ペインを閉じる | ペイン右上 `×` (タブ内最後の 1 枚は残る) |
| サイズ変更 | 分割境界をドラッグ (最小 80px) |
| フォーカス移動 | ペインをクリック / `F6` で巡回 (青枠が宛先) |

### ナビゲーション
| 操作 | 方法 |
|---|---|
| フォルダを開く | ダブルクリック / `Enter` |
| ファイルを開く | ダブルクリック / `Enter` (既定アプリ) |
| 親フォルダへ | `Backspace` / `↑ 上へ` ボタン |
| 再読み込み | `F5` (通常はwatcher が自動反映) |
| ツリーから開く | ツリーのフォルダ名クリック → フォーカスペインへ |

### 選択
| 操作 | 方法 |
|---|---|
| 単一選択 | クリック / `↑` `↓` `PageUp` `PageDown` `Home` `End` |
| 追加/解除 | `Ctrl+クリック` |
| 範囲選択 | `Shift+クリック` / `Shift+矢印` など |
| 全選択 | `Ctrl+A` |

選択中の件数はフッタ右端に表示。watcher の自動更新でも選択は名前で維持される。

### ファイル操作
| 操作 | 方法 |
|---|---|
| コピー / 切り取り | `Ctrl+C` / `Ctrl+X` (複数可・エクスプローラと相互運用) |
| 貼り付け | `Ctrl+V` (進捗はフッタに表示) |
| 削除 (ごみ箱) | `Delete` (複数可) |
| 名前の変更 | `F2` (拡張子手前まで選択された状態で開く) |
| 新しいフォルダ | `F7` |
| 新しいファイル | `F8` (空ファイル・上書きなし) |

リネーム/新規作成の入力欄は IME (日本語) 対応。`Enter` 実行 / `Esc` キャンセル。

### 右クリックメニュー
- **行の上**: 開く / コピー / 切り取り / 貼り付け / 名前の変更 / 削除 /
  新しいフォルダ / 新しいファイル
- **背景**: 貼り付け / 最新の情報に更新 / 新しいフォルダ / 新しいファイル
- 選択外の行を右クリックするとその行を選択、選択内なら複数選択を保ったまま。

### ドラッグ & ドロップ
| 経路 | 動作 |
|---|---|
| ペイン → 別ペイン | ドロップ先ペインの表示フォルダへ転送 |
| エクスプローラ → FastFiler | 同上 |
| 移動 / コピー判定 | 同一ボリューム = 移動 / 異なる = コピー (エクスプローラ準拠) |

選択中の行をドラッグすると選択全体を運ぶ。FastFiler → エクスプローラ方向は未実装。

### 並べ替え
列見出し (名前 / サイズ / 種類) をクリック。再クリックで昇順/降順 (▲▼)。
フォルダは常に先頭。

## 3. セッション復元

以下が自動保存され、次回起動時に復元される
(`%APPDATA%\FastFiler\gpui_session.json`):

- タブ一覧とアクティブタブ
- 各タブの分割構成 (方向・比率) と各ペインのフォルダ・フォーカス
- ワークスペースツリーの表示状態・幅
- ウィンドウの位置とサイズ

保存は変更の 800ms 後 (デバウンス) とアプリ終了時。

---

## 4. トラブルシューティング

- **一覧が更新されない**: `F5`。ネットワークドライブは watcher が効かない場合あり。
- **貼り付けが無効 (淡色)**: クリップボードにファイルが無い状態。
- **セッションを初期化したい**: アプリ終了後に
  `%APPDATA%\FastFiler\gpui_session.json` を削除。
